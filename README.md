# Evidence Desk

Local-first evidence logger and pack generator for field operators.

Companion to Operator Desk (quoting) and QuantumGuard (verification).

Open `index.html` in any modern browser. Works offline after first load. All data stays in localStorage on the device.

## Features

- Job intake (client, address, description, notes)
- Timestamped evidence entries
- Optional photo capture (camera or file) with SHA-256 hash
- Export QuantumGuard CONTRACT-v1 compatible payload (ready for signing)
- Client acknowledgment checkbox
- Printable summary
- Dark mode, mobile-first

## Run

Double-click `index.html` or open in Chrome/Firefox/Safari. No install. No account. No network after load.
